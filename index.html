由瀏覽器直接用 Web Audio API 產生純正弦波。唔經 YouTube、 影片壓縮或變速演算法，適合做 20 Hz～20 kHz 左右耳「相對比較」。

安全提示： 呢個頁面唔係醫療級 audiometer，亦無法知道你耳機實際輸出幾多 dB SPL。 開始前請先將系統／耳機音量調低，唔好因為高頻聽唔到就不斷加大音量。 如果出現耳痛、耳鳴加劇、耳塞感、眩暈或明顯不適，立即停止。

左右耳平衡測試 v4

以下兩個模式量度嘅係目前耳機 + DAC + 配戴 + 耳朵整條鏈路嘅相對差異。 結果使用 dBFS，唔係臨床 dB HL，亦唔可以診斷聽力損失。

A. 半自動 Threshold Staircase

程式會隨機安排左右耳／頻率，畫面唔顯示當前測試邊一耳。每次短音後只答「聽到」或「聽唔到」； 系統會自動調整數位電平並估算相對聽閾。

尚未開始
演算法使用 reversal staircase：初期以 6 dB 步進，取得兩次 reversal 後改為 3 dB； 最多測至 −24 dBFS，唔會因為「聽唔到」而無限制增加輸出。

B. Equal-Loudness A/B

一邊固定 −42 dBFS，另一邊由你微調，直到主觀上兩邊一樣響。 呢個模式量度「等響所需相對增益」，唔係最低可聽閾值。

點樣解讀 R − L？

正數：右耳需要較大數位訊號先達到 threshold，例如 +5 dB 即右耳相對要大約多 5 dB。

負數：左耳需要較大數位訊號。

但呢個差值包含耳機左右單元、配戴密封、耳道形狀等因素。 尤其 12～16 kHz，幾毫米耳機位置變化都可能令結果改變，所以應該重測，而唔好用一次結果下醫療結論。

建議測試方式

  1. 先將作業系統／耳機音量調到偏低，測試期間盡量唔郁系統音量。
  2. 如果測一般頻段，建議由 500 Hz 或 1 kHz 開始，確認左右耳都可以舒服聽到。
  3. 之後可以向下測 250、125、80、40 Hz，或者向上測 2、4、8、12、14、15、16 kHz；每個頻率只播放短音。
  4. 如果某頻率右耳聽唔到，先降低頻率再確認，唔好直接大幅加音量。
  5. 同一頻率重複測幾次，亦可以重新戴一次耳機，睇結果有冇變。
  6. 重點係左右耳相對差異，唔好將「最高聽到幾多 Hz」當成臨床診斷。
技術說明

本頁使用 OscillatorNode 產生 sine 正弦波， 再經過短暫 fade-in / fade-out，避免播放開始／停止時產生 click。

左右耳輸出由獨立 GainNode 接入 ChannelMergerNode， 唔使用影片播放速度或 pitch-preservation DSP。

但最終結果仍然會受耳機頻率響應、左右單元誤差、耳機位置、 DAC／音效處理、作業系統音量及耳道形狀影響，所以唔可以代替校準 audiometry。

此工具只供非醫療用途嘅 20 Hz～20 kHz 相對比較、Threshold Staircase 與等響實驗。若近期曾出現單側突發耳鳴， 並伴隨持續聽力下降、左右耳明顯不對稱、耳塞感或眩暈，應由耳鼻喉科／聽力師作正式檢查。
